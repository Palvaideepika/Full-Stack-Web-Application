# Full Stack Web Application

A full-stack web application developed using modern web technologies, featuring responsive frontend design, REST APIs, database integration, authentication, external API integration, Redis background jobs, and server-side caching.

## Features

- Responsive web interface
- HTML forms and validation
- Dynamic DOM interaction
- RESTful CRUD APIs
- MongoDB database integration
- User registration and login
- Password hashing with bcrypt
- JWT authentication and authorization
- External API integration
- API rate limiting
- Error handling
- OAuth investigation
- Redis background job processing
- Server-side caching
- HTTP request logging

## Technologies

- HTML
- CSS

- Node.js

Installation

Clone the repository and install the dependencies:

npm install

Create a .env file using .env.example and provide your own environment variables.

Start the application:

node server.js

The application runs locally on:

http://localhost:3000
Security

Sensitive credentials are stored using environment variables and are not included in this repository.
